## 已知問題 / 後續建議
- 分解後圖元保留自身圖層/顏色（圖層 0 與 BYBLOCK 不改為參照的屬性）
- R12 不支援非等比例（X≠Y）參照的分解（需 ELLIPSE，報錯不降級）；R12 圖塊名稱不可含空白
- 既有參照不會隨 add_attdef 自動補上新屬性（無 ATTSYNC）；屬性值僅單行（不支援多行屬性 MTEXT）
- modify_insert 的比例/旋轉僅支援 XY 平面上的參照；不支援 MINSERT 陣列參數、動態圖塊、XREF、XCLIP
- 非 Unicode 字碼頁圖面（R12/R2000）的中文圖塊名稱重開後仍為跳脫字串（待 T086）
